# Changelog

## v3.2.5

Aggiornamento esclusivamente relativo al front-end, basato sulla versione v3.2.4.

Il contatore `experiment accepted` utilizza un triangolo pieno verde orientato verso l'alto.

Il contatore `experiment rejected` utilizza un triangolo pieno rosso orientato verso il basso.

La dicitura `audited PCB accepted` è stata sostituita con `audited nodes accepted` nella fascia KPI e nel pannello delle evidenze sottoposte ad audit.

La dicitura `audited exact PCB accepted` non è stata modificata.

Le API, il mining, RandomX, TEP, Stratum, nginx, il verifier e i servizi di sistema non sono modificati dalla versione v3.2.5.
